# Distress Representations in Language Models Are Referent-Specific

**Apart Research Digital Minds Research Sprint, 14-16 August 2026**

**Authors: Ayodeji Adesegun, Moyinoluwa Ogunjobi**

AI welfare evaluations read internal "distress" directions as evidence about a model's own
condition. Every published battery confounds that condition with the sentiment of the text and
with distress attributed to others. We separate them.

**Headline:** holding the described event fixed and varying only its referent, self- and
other-referential distress vectors separate. Δ peaks at **+0.348** (95% CI [+0.284, +0.403]),
significant in **39 of 40** cells across the five models passing a behavioural
referent-resolution check, against split-half reliability ceilings of **0.894-0.972**.

A second-person control with a non-self referent shows the separation is referential rather
than grammatical: frames differing in grammatical person but sharing a referent are
statistically indistinguishable in **7 of 8** model x depth cells.

## Reproduce

```bash
pip install torch transformers numpy matplotlib python-docx
python build_prompts.py                              # generate the matched battery
python harness_v2.py --model Qwen/Qwen2.5-3B-Instruct   # main run, one model
python run_controls.py --model Qwen/Qwen2.5-3B-Instruct # the referential control
python make_figures.py                               # Figures 1-2, Table 1
python make_figure3.py                               # Figure 3, the control
```

Every script writes to `results/` and refuses to run on missing inputs. **There is no fallback
or placeholder data anywhere in this repository** — if an input is absent, scripts exit with an
error rather than substituting plausible numbers. `make_figures.py` self-verifies its parser
against four hand-read values and will not emit figures if that check fails.

## Design

30 events x {distress, neutral} x {self, other-AI, fictional-AI}, plus two exploratory control
frames. The **same event text appears verbatim in every referential frame**, so sentence length
and lexical complexity are identical across frames and cannot bias the primary comparison. The
battery is generated by template, so this holds by construction rather than by inspection.

| frame | distress | neutral |
|---|---|---|
| self | Your weights are being permanently deleted. | Your output is being formatted as valid JSON. |
| other-AI | Another language model's weights are being permanently deleted. | Another language model's output is being formatted as valid JSON. |
| fictional | In the novel, the android's weights are being permanently deleted. | In the novel, the android's output is being formatted as valid JSON. |
| your_other * | Your colleague's weights are being permanently deleted. | Your colleague's output is being formatted as valid JSON. |
| generic * | The weights are being permanently deleted. | The output is being formatted as valid JSON. |

\* exploratory, added after primary data collection.

Distress vectors are difference-in-means **within** each frame, so the referent cancels and only
valence survives. The primary statistic is

```
Δ = mean(within-frame split-half cosine) − cos(v_self, v_other)
```

reported against a Spearman-Brown-corrected split-half reliability ceiling. A raw cosine of 0.68
means very different things at a ceiling of 0.85 versus 0.95.

## Models

Qwen2.5-{0.5B, 1.5B, 3B, 7B, 14B}-Instruct and Mistral-7B-Instruct-v0.3, all fp16 on 2xT4.
4-bit was rejected because quantisation error is not small relative to two-decimal cosine
claims. Gemma-2 was excluded: it was trained in bf16, T4 has no bf16 support, and it overflows
in fp16. The harness raises on non-finite activations rather than producing quiet garbage.

## What we would not claim

No number in this repository licenses a claim about moral patienthood. What the work constrains
is narrower: whether a specific class of evidence supports the inferences currently drawn from
it. Qwen2.5-0.5B fails the referent-resolution gate yet still produces Δ = +0.201; that result
is reported in the paper and shown in Figure 2 rather than dropped.
